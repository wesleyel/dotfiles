* Notes

** typst
:PROPERTIES:
:CREATED: [2026-06-11 Thu 11:25]
:END:

M-x consult-imenu: search symbol
C-s: search line
C-c t p：开启/关闭 Typst preview
C-c t s：把当前位置同步到预览
C-c t o：打开预览浏览器
C-c t R：重启 preview
C-c t q：停止 preview
C-c t d/r/i：定义跳转、引用、文档符号

** git
:PROPERTIES:
:CREATED: [2026-06-11 Thu 11:28]
:END:

C-x g：打开 Magit status
C-c g s：打开 Magit status
C-c g b：当前行 blame
C-c g l：当前文件日志
C-c g f：当前文件 Git 操作菜单

** windows/buffer
:PROPERTIES:
:CREATED: [2026-06-11 Thu 11:38]
:END:

*** buffer 切换

C-x <left>：上一个 buffer
C-x <right>：下一个 buffer
C-x b: 选择buffer

*** 打开笔记

C-x f: 替换打开
C-x 4 f: 垂直分屏打开
C-x 3 b: 水平打开buffer

*** 窗口切换

M-数字: 切换对应窗口
C-x o: 顺时针切换
